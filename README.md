
## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [https://pattys-blog-backend.onrender.com](https://pattys-blog-backend.onrender.com) with your browser to see the result.




To test the app, use this [link](https://pattys-psi.vercel.app/)

## Testing OTP

Email sending is currently disabled, so no verification email will arrive. Whenever the app asks for an OTP (verifying your email after sign up, or resetting a forgotten password), enter:

```
123456
```
